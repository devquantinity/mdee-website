# mdee-website

Static site for M'Dee (MDEE Enterprise), a Penang sauce and cooking-paste maker.

Pages: `index.html`, `home-shop.html`, `recipes.html`, `how-it-works.html`,
`our-story.html`, `contact.html`. Images and icons live in `asset/`.

No build step. Open a file locally, or deploy the folder as-is.
